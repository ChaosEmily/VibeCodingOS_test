# Vibe Coding OS

> 一套基於「第一性原理」與「AI 原生開發思維」的輕量化開發操作系統。

Vibe Coding OS 不僅僅是一個文件夾，它是一套專為 AI 協作設計的**工作流協議**。透過預設的 `Skills` (技能包)，協助開發者從「語意模糊的點子」轉化為「邏輯嚴密的 App」。

---

## 🚀 核心開發思維：JS 動詞思考法

在 Vibe Coding 的世界中，我們將 App 拆解為三個原子維度：

1.  **名詞 (Data)**：定義基礎數據欄位（Schema / Atoms）。
2.  **形容詞 (CSS)**：定義視覺風格與呈現方式。
3.  **動詞 (JS)**：定義「當 A 觸發時，B 該如何運算」的邏輯引擎。

---

## 🛠️ 如何操作 Skills (技能包)

本專案的核心邏輯儲存在 `.agent/workflows` 目錄中。當你在 AI 入門的 IDE（如 Cursor, Windsurf, Claude Dev）中使用時，可以利用以下操作：

### 1. 觸發指令
在聊天視窗（CMD+L）中輸入 `/` 即可顯示可用的技能指令：

*   **`/vibe`**：主控台入口，引導你完成專案從 0 到 1 的建立。
*   **`/classify`**：判斷目前的點子是屬於 Page 還是 App，並提供技術選型建議。
*   **`/blueprint`**：協助你定義數據原子、物理定律與核心路徑，生成需求規格書。
*   **`/vibe-flow`**：提供 4 階段執行指南（地基 -> 大腦 -> 零件 -> 調優）。

### 2. 自定義與擴充
你可以直接編輯 `.agent/workflows/*.md` 文件來調整 AI 的行為邏輯。修改後存檔，下一次觸發指令時 AI 將自動採用新邏輯。

### 3. 多專案套用
只需將 `.agent` 文件夾複製到任何專案的根目錄，即可在該專案中啟用這套 Vibe Coding 技能。
